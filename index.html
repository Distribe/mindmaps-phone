Tags & fields

Colour key

This map's card colours and what each means, highest tier first. Drag a colour up or down to change the tiers. The bottom one is the faded tier: drag another colour there to make it the faded one. Base, just above it, is the colour new cards start in, so it stays put.

Tags

Labels for any card, e.g. "Part I" or "Objection". A card can have several; its first tag colours its edge and groups it in the list.

Fields

Extra information every card can fill in, e.g. "Chapter", "Status" or "Source". Tick List for a field that holds several separate items, e.g. "Evidence": add each one with + Add in the card panel. Tick Mark for a field shown as a small symbol in every card's top-right corner, which a click changes, e.g. a tick for the cards you've read.

Picking a tool shrinks this to a small bubble (click its icon to change tool). Esc or Draw again stops drawing; then click any drawing to move, resize or turn it. Ctrl+Z undoes.
